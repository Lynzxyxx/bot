Penyimpanan (Upstash Redis)

          
Semua file, konfigurasi, dan log server ini disimpan di Redis milikmu sendiri — bukan di disk Vercel (yang memang tidak permanen di serverless).

          

        

        

          
Isolasi per admin

          
Setiap admin (ADMIN_PASSWORD, ADMIN_PASSWORD2, …) punya ruang penyimpanan sendiri di Redis yang sama — file dan statistik tidak pernah tercampur antar admin.

          

        

      


      
      

        

          
Keep-Alive (pembangun Vercel)

          
Bot ini memakai webhook: Telegram yang menelepon server saat ada pesan, jadi bot tetap menjawab 24 jam tanpa perlu "dibangunkan". Endpoint di bawah tetap disediakan untuk memantau & otomatis memasang ulang webhook bila hilang.

          
          

          

          

        

        

          
Ping otomatis dari panel

          
Selama tab panel ini terbuka, panel memanggil endpoint di atas tiap 4 menit.

          
        

        

          
Ping dari luar (disarankan)

          
Daftarkan URL keep-alive di UptimeRobot atau cron-job.org (interval 5 menit, gratis). Vercel Cron bawaan (vercel.json) pada paket Hobby hanya boleh 1× per hari.

        

      


      
      

        

          
Bot Telegram

          
Token bot & ID owner dibaca dari config script kamu sendiri (config.js / .env / new Telegraf(token)). Panel tidak meminta token — cukup upload script lalu tekan Start.

          

          
          
          

        

        

          
Auto-restart (pemulih CPU)

          
Kalau CPU terus tinggi atau bot error beruntun, panel otomatis me-restart server (pasang ulang webhook + reset cache). Jeda minimal 5 menit antar restart.
